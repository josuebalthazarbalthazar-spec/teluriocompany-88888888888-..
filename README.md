# Telurio Company

> Soluções digitais e tecnologia para empresas.

## Sobre o projecto

Este repositório contém o projecto do website da Telurio Company, desenvolvido para apresentar a identidade da empresa, os seus serviços e os seus canais de contacto.

O objectivo é disponibilizar uma presença digital profissional, com uma interface moderna, navegação intuitiva e adaptação a diferentes dispositivos.

## Funcionalidades

As funcionalidades devem ser documentadas de acordo com a implementação real do website. Podem incluir:

- Apresentação institucional da empresa.
- Divulgação de serviços.
- Secção de contacto.
- Design responsivo.
- Navegação adaptada a dispositivos móveis.
- Ligações para canais de comunicação.

## Tecnologias

A stack tecnológica deve ser confirmada nos ficheiros do projecto, especialmente no `package.json`.

## Instalação e execução

### Pré-requisitos

- Node.js, caso o projecto utilize JavaScript ou TypeScript.
- npm ou outro gestor de pacotes compatível com o projecto.

### Instalar as dependências

```bash
npm install
```

### Executar em desenvolvimento

```bash
npm run dev
```

### Criar a versão de produção

```bash
npm run build
```

Os comandos acima aplicam-se se estiverem definidos nos scripts do projecto. Consulta o `package.json` para confirmar os comandos correctos.
